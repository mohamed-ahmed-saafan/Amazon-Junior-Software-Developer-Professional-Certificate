src folder components :

1- Main class: The entry point of the application. It ties together all components and manages the application's flow.

2- Book class: Represents a book entity with attributes like title, author, and publication year.

3- Library class: Manages a collection of Book objects, including methods to load, view, and handle books.

4- SortUtil class: Provides sorting algorithms for organizing the list of books by different criteria.

5- LibraryMenu class: Implements a user interface for interacting with the library, such as searching for books, exiting the program, and invoking different sorting methods.

6- UserInteractionLogger class: Logs user interactions, such as searches and sorting actions.

7- LibrarySerializer class: Handles the serialization and deserialization of the Library object, saving and loading the application's state.
